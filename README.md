# RESOLVE_TI

## Sobre o projeto
Desenvolvido para organizar e acompanhar solicitações de suporte dentro de uma empresa. O sistema permitirá cadastras chamados, consultar solicitações, atualizar informações e acompanhar o andamentos dos atendimentos.

## Tecnologias
Python

Django

Django REST Framework (planejado)

SQLite

Poetry

Git e GitHub

## Objetivo de aprendizado
Este projeto tem como objetivo desenvolver minhas habilidades em programação backend, utilizando Python e Django para construir uma API REST.

Durante o desenvolvimento, pretendo praticar organização de código, gerenciamento de dependências, versionamento com Git e testes automatizados.
